# Night Souq — Frontend

واجهة متجر إلكتروني مبنية بـ React + Vite، بتدعم تسجيل الدخول، التسوق، تفاصيل المنتجات، الحجز، الملف الشخصي، ولوحة التحكم للمدير.

## التشغيل

```bash
npm install
npm run dev
```

سيتم تشغيل التطبيق على:

```bash
http://localhost:5173
```

إذا كان الـ backend يعمل على منفذ مختلف، حدّده داخل متغيرات البيئة أو إعدادات الـ API داخل المشروع.

## هيكل المشروع

- src/api — إعدادات الاتصال بالسيرفر وواجهات الـ endpoints.
- src/context — إدارة الجلسة والتوكن والمستخدم الحالي.
- src/components — مكونات مشتركة مثل Navbar، Card، Loader، Footer، ProtectedRoute.
- src/pages — الصفحات الأساسية مثل Home، Login، Register، Checkout، Profile، NotFound.
- src/pages/admin — لوحة التحكم الخاصة بالأدمن.
- src/styles — ملفات التصميم والـ theme.

## المميزات

- متجر مع بحث وتصفية حسب السعر.
- صفحة تفاصيل المنتج مع معرض صور.
- تسجيل حساب وتسجيل دخول مع تأكيد البريد الإلكتروني.
- استرجاع كلمة المرور.
- الحجز وإدارة الطلبات.
- الملف الشخصي وتحديث البيانات.
- لوحة تحكم لإدارة المنتجات والمستخدمين والمدفوعات.
- دعم الوضع الداكن والمضيء.

## ملاحظات سريعة

- المشروع يعتمد على الـ API الخاصة بالخادم المرتبط به.
- إعدادات الاتصال موجودة داخل مجلد src/api.
- إذا أردت تشغيله محليًا بالكامل، تأكد أن الـ backend يعمل بشكل صحيح أيضًا.
